# 玻璃三维互联与路由文献分类、证据抽取记录

检索截止：2026-10-28；分类日期：2026-10-28。供主报告证据核查使用，不代表已复现论文。A=取得并阅读原始全文/作者稿相关章节；B=原出版者摘要/片段；C=元数据或机构资料。相关性R：10为直接竞争先例，8为核心方法或工艺，6为上下游背景。未披露不等于没有。

## 最重要的边界结论

1. **不能以“首次将三维、曲率、间距引入自动布线”为创新。** Yoo等2016全文明确已有等光程、最小曲率半径、最小波导间距的三维设计工具，以及256波导实物（Fig.7）。Ling等OFC2021摘要也明确自动3D路由。
2. **不能以1024为首次大规模光子路由。** LiDAR2预印本v1 Table III已有1024 nets的Bennes以及8195 nets的TeMPO。它们是平面PIC内部连接，不等同于本项目端到端1024波导，但证明千连接算法规模本身不是空白。
3. Corning2025摘要报告超过1024玻璃波导互联，工艺是**银离子交换**，不能当作飞秒直写任意三维波导的证据。全文未取得，暂不能确认该大规模电路的全通道测量或准确连接表。
4. **最贴近应用的直接竞争文献**是Castro等OFC2025玻璃内嵌folded Clos互联，而不是HBM位宽。它明确是3D直写并进行了400 Gb/s流量测试；未取得全文，通道数未知。
5. IEEE802.3官方托管的Castro2026演示第13页明确指出其所讨论的3D玻璃Shuffle损耗高于optical-flex Shuffle。这是厂商工程报告，不能推广为所有工艺的永恒定律，但必须列为反面证据。

## 已精读全文的重点记录

### G05：2016三维设计工具的能力边界

原始全文本地 `glass/yoo2016.pdf` 与 `glass/yoo2016.txt`，合法OA全文XML `glass/yoo2016.xml`。第4页“3D multi-ring waveguides”明确路由工具维护等光程、最小曲率和间距；第4–5页“3D waveguides for optical phased arrays”说明1×256变为16×16，Fig.7在PDF第7页展示设计及端面实物。论文末段也指出ULI串行写入造成制造扩展困难。该文为综述而非开源算法论文，因此其能力披露不能代替可复现运行时间、任意拓扑成功率以及大规模DRC证明。

### G12：玻璃包装性能不只由中心线决定

原始全文本地 `glass/uli2023.pdf` 与 `.txt`。Sec.2讲解的是离子交换波导和电/光封装；Sec.3分别介绍激光切割和端面质量；Sec.4讨论连接器对准与连接测试。应引用它论证“端口公差—自对准—端面质量—重复插拔”的设计链，而不是把超快激光标题理解为飞秒直接写光芯。省掉额外光纤装配不等于完全省掉连接器、对准和检验。

### G17：复现应绑定版本

固定v1 HTML可逐表核查；本地 `glass/lidar2.pdf` 是访问时默认最新版本，应先读首页再决定引用年和版本。v1 TableIII的net数与TableVI的运行时间是设计自动化算例，电路包含内部器件与交叉，不能按其net数量宣称外部I/O规模；其损耗采用模型，非成千条玻璃芯片实测。其方法可借鉴曲率感知、端口保留区、拥塞历史代价、分层复用与DRC，但z自由度、深度依赖工艺、三维邻近串扰、写入次序不在本轮已核查能力中。

### G18：2026弯曲工艺的机会与不能混同的指标

Wiley全文于2026-06-25首次发表，Fig.8固定Δx190.5 μm、总长10 mm，Δy1.4 mm时比较弧形、余弦与TOA-cos；Fig.9是4路FI/FO、2.5×2.0 mm²、4芯40 μm与127 μm阵列接口；文中明确尚未完成完整组装。文章把某参数称Reff，本文路由约束必须用三维中心线 `R(s)=1/κ(s)`，除非证明二者等价，否则不能直接将Reff3.34 mm填为本组Rmin。

## 仍需补证的高优先级问题

- G01全文尤其>1024电路图、连接数、全部通道是否逐条测量、IOX波长及半径/交叉的测量条件。
- G04原理器件的实际规模、波导材料、写入或多层工艺；不能仅凭“toward1000”认定实际千路。
- G06全文的算法表示、等长与曲率/间距是否同时考虑、真实通道数。
- G07实际连接表、端口数、体积、插入损耗分布、400 Gb/s实验配置以及加工时长。
- G08全文的84通道端口布局、最坏损耗与装配良率、是否提供自动路线算法。
- 全部研究中的“未明确自动布线”应标NR/未披露，不填否。通道数NR也应保留，不用图中近似数替代。
