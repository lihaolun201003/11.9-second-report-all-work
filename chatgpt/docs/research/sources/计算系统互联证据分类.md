# 系统互联资料：证据分类与技术抽取

检索截止：2026-10-28；访问日期：2026-10-28。本文为资料分类工作底稿，供主报告交叉引用，不是系统已实现性能说明。元数据优先以原文首页与 Crossref 逐 DOI 查询结果核对。评级：A=原论文全文定位；B=官方完整网页/技术材料；C=官方索引或摘要，可确认存在但不可抽取未公开实验；D=二手线索，不作数值依据。RCS 为对当前课题的相关性（10分），不是论文质量或商业成熟度。

## 一、最重要的纠偏

1. HBM2E/3/3E 的 1024 位电接口不能转换成“需要1024条玻璃波导”。应先确定总数据率、串行化、WDM数、单双向、光源供给和编码。Intel OCI 给出真实反例：每方向64个32 Gb/s数据通道通过8条信号光纤传输，每纤8波长；双向使用8对光纤。
2. 光HBM确有直接研究，不能写“没有相关研究”。Ou 等2025年论文明确保留传统HBM结构，通过EIC/PIC及CPO连接多栈模块；其收益来自建模，并非已加工的HBM—玻璃波导样机。
3. 内存池化既有支持也有反对结果。Pond 的收益依赖8—16 socket小池、工作负载分类和分层放置；Google HotNets2023质疑DIMM离散容量、额外交换/布线成本及调度替代方案。不能将任一论文写成普遍结论。
4. 截止2026年，HBM4已有厂商量产声明，CXL4.0已发布。HBM3E、CXL3.0可作历史基准，不能称其最新。
5. NVIDIA实时页面发生版本差异：2026年1月CES稿为Rubin NVLink 3.6 TB/s/内存22 TB/s；2026-10-28产品页为3 TB/s/19.2 TB/s，不能混用。

### SYS07 — Intel OCI官方演示（B；RCS 9/10）

- 作者：Intel；2024-06-26；题名：Intel Demonstrates First Fully Integrated Optical I/O Chiplet。

## 四、系统论文精读与正反证

### SYS15 — 多栈光HBM（A；RCS 9/10）

- 作者：Yanghui Ou、Hengrui Zhang、Austin Rovinski、David Wentzlaff、Christopher Batten。
- 2025，IEEE Computer Architecture Letters 24(1):49—52；DOI：https://doi.org/10.1109/LCA.2025.3540058
- 机构：Cornell、Princeton、NYU。全文：https://www.csl.cornell.edu/~cbatten/pdfs/ou-optical-mem-llm-cal2025.pdf
- 实际阅读：全文4页可解析；§II、Figs.2—4为设计，§III、Figs.5—6为LLMCompass模型评估。
- 结构：计算MCM中6组EIC/PIC，每组48纤、127µm pitch，16组光通道；一组光通道=comb供光/TX/RX三纤；信号纤64波长×16 Gb/s约1 Tb/s。全系统288物理纤，其中96 TX、96 RX、96供光。论文设计给12 TB/s与576GB，不能把“channel”16误认为16根纤。
- 结果边界：4096GPU、1T模型训练MFU改善1.4倍；1T decode平均4.23倍须把L2提升到24 TB/s；不改L2为1.67倍。属于建模，未加工封装。
- 原文自述：不直接给HBM stack集成光互联；增加封装复杂度，cost effectiveness留作future work。不同于无源玻璃重排。论文引用表中Pond年份列2024有误，应以Pond原文/Crossref的2023为准。
- 本课题：可作未来封装周边固定扇出例子，不能作为本项目已经能连接HBM的证据。也不能直接从HBM位宽导出1024根。

### SYS16 — Pond支持性系统证据（A；RCS 8/10）

- 作者：Huaicheng Li、Daniel S. Berger、Lisa Hsu、Daniel Ernst、Pantea Zardoshti、Stanko Novakovic、Monish Shah、Samir Rajadnya、Scott Lee、Ishwar Agarwal、Mark D. Hill、Marcus Fontoura、Ricardo Bianchini。

### SYS20 — OCM：DDR光内存系统原论文（A；RCS 8/10）

- 作者：Jorge Gonzalez、Mauricio G. Palma、Maarten Hattink、Ruth Rubio-Noriega、Lois Orosa、Onur Mutlu、Keren Bergman、Rodolfo Azevedo；2022；题名：Optically connected memory for disaggregated data centers；J. Parallel Distrib. Comput. 163:300—312。
- DOI：https://doi.org/10.1016/j.jpdc.2022.01.013 （Crossref逐DOI核定，原始JSON已保存）。
- 合法作者全文：https://lightwave.ee.columbia.edu/sites/lightwave.ee.columbia.edu/files/content/publications/2022/optically_connected_memory.pdf （13页，可解析；出版社直取403后已找到作者稿）。
- 定位：§3架构与Fig.3、§4.2系统级性能、§4.3能耗估计、§6结论。
- 内容：保留DDR DRAM，以MRR/WDM和SER/DES构造点到点连接，并研究光交换重分配。4个DDR4通道由2根纤承载，1.02 pJ/bit为从器件模型构造的SiP链路估计；最高5.5倍是对40G NIC远端内存的系统仿真，不是相对本地HBM的实测提升。
- 条件：文中显式包括光纤往返2/4/6m时延（Table 1附近）和NIC基准；模型及基线代际决定其适用性。不能把2015反证价格与2022器件模型直接相减。

## 五、可用于报告的计算（均为推导，不是实验）

- 设总单向净数据率D、每波长线路速率r、每纤W个波长、有效负载效率η，则信号纤下界N≥ceil[D/(rWη)]。双向、备用、时钟/供光、分区约束需另加；不是一个普适精确物理纤数公式。
- HBM3E以1.2 TB/s单向量级为例，D=9.6 Tb/s。若r=100 Gb/s、W=8、η=0.8，信号纤下界15根；这只是人为参数的量纲演示，不是可替代HBM接口设计。若W=1则120根，说明1024位不约束1024光路。
- 光程传播延迟t≈n_g L/c。若仅为估算取n_g=1.5，则5ns/m，往返10ns/m；1m/10m/100m对应单程5/50/500ns。应把此项同E/O、O/E、SerDes、FEC、协议、交换排队、控制器及DRAM访问分开。n_g=1.5为示例假设，不是本课题组玻璃测量。
- 光I/O越来越快不意味着无源固定Shuffle创造了这些带宽；无源器件只需在目标波长、模场、偏振、功率和预算下保持连接映射。

## 六、直接应用判断

最可信的直接定位是多光口模块之间的固定重排、光纤阵列与芯片阵列扇入扇出、板/封装边界高密度被动映射；本系统必须给出完整端口坐标与连接表。GPU—HBM直连是需主动光电与协议协同的未来系统背景，本毕业设计不能独立完成。GPU集群真实需求也不能自动证明某个玻璃芯片恰需1024波导；需用具体多模块纤数和连接拓扑构造研究规模，并明确“研究示例”。
