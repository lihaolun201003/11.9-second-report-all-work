## 1. 方法与口径（可复现）

1. 候选池来自 `analysis/crossing_intervals.json`，其 `baseline_dir` 是冻结 E5 基线；候选的 `s_start/s_end` 是 E5 路线**本体 flat** 的弧长，因此候选必须用 E5 路线重建。`experiment_C`（已接受 2440 交叉布局）中已转 Native 3D 的 55 条路由本体几何已改变，其 1073 个候选标记 `route_modified_in_native`，只做 E5 世界分析、不参与 Native 复核。
2. 每个候选按 `route_model.duck_out(baseline_route, body_flat_index, s0, s1, target_z)` 精确重建；direct（Z1/Z2 接口本体，0 个 fanout transition）路线的 `duck_out` 会留下过期 `body_heights`，分析中二次推导 metadata 后再做几何检查（原始 metadata 错误单独统计，见 §2.2）。
3. 真 3D 检查与生产 guard 同口径：
   - 同一物理高度：严格 D56（0.08 mm 中心线）全平面索引；跨物理平面 flat 对按 0.05 mm 层间距规则视为合法；
   - 不同物理高度：S 曲线 / 目标高度 flat 与其它路由 flat / transition 的真实 3D 中心线距离，工艺规则阈值 0.05 mm；生产 guard 采样安全余量对应 0.061 mm；
   - 自身间距：`self_clearance_violations`（0.05 mm）。
   - **guard 口径** = 生产 World/guard 的判定（含采样余量，候选在此口径被拒即实验无法采纳）；**硬口径** = 用精确 S 曲线参数化（两段 R15 圆弧）局部细化到 <1e-3 mm 后仍 <0.05 mm 的真实违规；介于两者之间的是 near-miss（生产会被保守拒绝，但精确距离其实 ≥0.05 mm）。
4. 阻断分类：可移动 vs 冻结 manual（`assignment_1024.csv` 的 `manual_group` 非空 = 冻结 U，共 368 条）；分组 (a) 1–3 可移动硬阻断、(b) ≥4 可移动硬阻断、(c) 含 manual 硬阻断、(d) 自身几何/记账失败、(e) world-clean、(f) 仅 near-miss（无硬阻断）。
5. 生产 guard 交叉验证：确定性抽样 60 个候选，`guard.local_world_check` 报出的阻断/类型全部被快速扫描覆盖 （一致率 100.0%；fast-clean 但 production 报错矛盾 0 个；前 15 个另跑 `guard.candidate_guard` 记录阶段分布）。
6. 已接受 Native 布局的生产复核：20 个候选上 `local_world_check` 与快速扫描一致率 100.0%，双方都 world-clean 的 0 个。

### 2.5 对已接受 Native 布局（experiment_C）的敏感性

- 可复核候选（路线未被 experiment_C 改动）**4314** 个；与 E5 世界相比硬阻断集合完全相同 **2308** 个（53.5%）。

## 3. 机制解释（为什么几何可行 ≠ 真 3D 可行）

- **主因是 transition_vs_flat**：换层 S 曲线穿过所有中间物理层，其它路由在那些高度上的 flat 只要落在 S 曲线 1–7 mm 的落点范围内，真实 3D 距离就 < 0.05 mm。不同物理平面之间没有 crossing 豁免，这是硬冲突。
- 一次 excursion 的可用空间不是 2D 走廊，而是**贯穿所有中间高度的3D 柱体**；1024 条路由 + 21 个高度使大部分目标高度的 S 曲线 footprint 都被多条 flat 穿过。
- **目标高度 strict-D56** 是第二类阻断：middle flat 与目标高度上其它路由 flat 的 2D 距离须 ≥0.08 mm（或合法横穿），目标高度占用越满越难。
- 目标高度离本体越远，S 曲线穿过的中间高度越多、阻断路由数越多；这解释了 per-target-height 的差异（§4），也解释了上一轮 55 条被接受的 Native 3D 路由集中在低层 L6/L7/L8/L20（占用较少）。

## 6. Route 129（net=16）专门结论

route 129 本体 L6（z=-0.150 mm），cluster s=20.96–68.20 mm 内 22 个交叉；analysis 在 **7 个目标高度**给出 net=16 候选（另有 13 个 net<16 的候选见 JSON）。

- **verdict**：net=16 的 **7 个目标高度在生产 guard 口径下全部被拒**，单次 excursion 直接采纳不可行。
- 物理硬阻断并集 **7** 条路由；出现最多的：r120×6, r697×4, r37×1, r224×1, r516×1, r678×1, r1004×1。其中 **r120（L7 flat，在 excursion 起点正上方约 31 µm）** 挡了 6/7 个目标高度，是最关键的一条。
- 最好的两个目标高度：**L4**（0 个硬阻断，仅 3 个 near-miss）与 **L8**（1 个硬阻断 [120] + 4 个 near-miss）。
- 含义：L4 在**精确物理口径下已经合法**，只差 guard 的采样余量（3 条并行/邻近 flat 在 0.051–0.058 mm）；L8 只差把 r120 移开（或把 excursion 沿路径错开 ~mm 级）。其它目标高度需 2–5 条硬阻断路由。
- 结论：route 129 的 net=16 **不能**靠移动 1–3 条路由直接拿到；最小可行路径是"取 L4（或 L8）目标 + 处理 2–5 条 near-miss（精确复核/微调）+ L8 时移开 r120"，之后再按生产 guard 完整复核。
