# 50 μm 规则审计（0.08 / CLEARANCE / 层距 / 在线 world）

## 1. 结论

- 已确认工艺：玻璃 1 mm、Z1=0、Z2=0.5、最小物理层距 50 μm、上下双向。
- **没有确认**“任意两条不同波导必须相距 80 μm”的全局工程要求。
- 本轮默认规则改为：
  - 不同物理平面：`|dz| >= 0.05 mm` 即合法；XY 重合不因跨层而非法。
  - 同一物理平面：继续使用原有二维 D56 / 受控交叉规则；不把旧 80 μm 全局常量套到同层。
  - 三维过渡 vs 其他波导：真实三维中心线距离 `< 0.05 mm` 才拒绝；过渡不能真实穿透。
  - 物理层栈：每个相邻路由层/接口平面必须 `>= 0.05 mm`。
- 旧 80 μm 模式作为 `legacy_80um` 保留，用于复现旧实验，不参与新默认。

## 2. 使用点分类

| 使用点 | 旧含义 | 本轮处理 |
|---|---|---|
| `validate_l3d.CLEARANCE_MM` | 旧全局中心线 80 μm | 新 50 μm 模式；物理层/过渡/跨层检查统一 0.05 |
| `physical_planes_too_close` | 层间距 <80 μm 报错 | 改为 <50 μm；正好 50 μm 只警告 |
| `flat_cross_plane_too_close` | 跨平面 flat 的真实 3D 距离 <80 μm | 新规则：层间 `|dz|>=50 μm` 合法，XY 重合不再违规；<50 μm 才拒绝 |
| `transition_vs_flat` / `flat_vs_transition` / `transition_vs_transition` | 真实 3D <80 μm | 新阈值 0.05 mm；保留真实穿透拒绝 |
| `World` / `ClearanceWorld3D` | 构造时默认 0.08 | `lift_cross` 明确把 `clearance` 传入 `World`；新构建使用 0.05 |
| `FastClearance` / `ApproxClearance` | 搜索加速的保守 80 μm | 新构建使用 0.05；仍只是快速证书，最终以严格 validator 为准 |
| 同层 D56 (`fslw.CLEARANCE_MM=0.08`) | 同层 2D 边距规则 | 保留为同层二维规则，不当作跨层全局阈值 |
| 接口端口占用/宽度/间隙 | 旧 2D 工艺/仿真常数 | 不动；不因本轮规则放宽 |
| 旧实验 A/B | 80 μm 规则下的违规 | 只做重新验证，不覆盖原结果；原目录保留 |

## 3. 在线 world 与最终 validator 一致性修复

发现并修复了两个问题：

1. `CrossingLifter` 创建 `World(self.stack)` 时没有把 lifter 的 `clearance` 传入，在线 world 仍默认 0.08；导致 50 μm 新规则下构建阶段仍用旧阈值。
   - 修复：`World(self.stack, clearance=self.clearance)`，两处构造点均已修复。
2. `World.check_route` 没有在线检查“候选平面与已有平面的高度差 <50 μm”。
   - 修复：加入真实层间 gap 检查；候选 flat 与已有 flat 的 `0<|dz|<clearance` 直接拒绝，正好 50 μm 放行。
3. `validate_l3d` 的跨平面 flat 检查此前比较真实 3D 距离与统一 80 μm；新模式下 `CLEARANCE_MM=0.05`，层间 50 μm、XY 重合的真实距离正好 50 μm，合法；<50 μm 才拒绝。
4. 同层 D56 仍按原二维规则独立处理；没有把 80 μm 跨层规则混入同层，也没有禁止受控交叉。

## 5. 旧 A/B 重新验证

| 实验 | 旧 80 μm 违规 | 新 50 μm 违规 | 消除 | 新规则剩余 |
|---|---:|---:|---:|---:|
| 旧 A（12 层冻结 XY，644 条） | 330916 | **9957** | 320959 | 物理层 .48/.53 距 Z2 接口仅 20/30 μm + 300 个 flat 跨层明细 |
| 旧 B（12 层目标重布，726 条） | 388276 | **11777** | 376499 | 同上，另加其自身几何 |

这说明原 330916/388276 中绝大多数来自错误的 80 μm 规则，而不是真实穿透；但旧 12 层栈的 `.48/.53` 距接口 `.5` 仅 20/30 μm，**不能**因阈值改为 50 μm 就保留；新实验使用了修正后的 `.45/.55` 等高度。

## 6. 最终合法结果

- 实验 B（18 层重建，目标层布线）：**723/1024**，0 违规。
- 实验 C（B + R15 目标层恢复）：**809/1024**，Z1 416、Z2 393、人工 U 256/256、Z2 接口 48/48，0 违规，最小净空 **0.052673907 mm**。
- 旧 801/1024 保留，不删除；它是在旧严格规则下的有效基线，但不是新工艺模型的上限。
