## 5. 估计的边界与限制因素

1. **shadow / 可放置性是第一限制**：source 端 1.25 mm 空窗由候选区间“吸附”自动满足（`shadow_source` 冲突 0 次），代价是区间被迫伸缩；真正无法构造候选的是 `no_shadow_clear_placement` 90 次与 `straight_run_too_short` 826 次，落点侧 shadow 冲突 `shadow_target` 1196 次。
2. **直线段可用性 + 3D 间距**：430 个簇（×20 个目标高度不生成候选）完全落在圆弧段或直线段端部 shadow 内；另有目标高度上与其他 flat 重叠/相切/间距风险（target_overlap_middle 929、target_overlap_shadow 940、target_tangent_contact 379 次），以及 S 曲线在中间高度与其他 flat 的 3D 间距不足（transition_clearance 0 次）。
3. **目标高度占用**：中段越长、目标高度越拥挤，added 越多。各目标高度的可行候选数与最好 net 见 JSON 的 `target_height_occupancy`；其中手工高度（目标 z 属于 L2–L5/L10–L13）被冻结手工路由占用，估计净收益整体偏低。
4. **真 3D 间距是比 shadow 更紧的限制**：几何可行候选只有 1.35% 通过 world_3d_ok（target_spacing=8，transition_clearance=11380），说明中部换层的 S 曲线在垂直穿越时极易靠近其他高度的 flat；实验 B 应优先使用 `world_3d_ok=true` 的候选，并用完整 3D 校验器复核。
5. 本估计不重新执行完整 D56 pair 审计，也不考虑多路线同时换层后的相互影响；实验 B 必须用精确评估（`native3d.guard` / `native3d.single_route.evaluate_candidate`）复核候选。
6. 中段长度：advisory max = 120 mm（`MAX_MIDDLE_MM`），可行候选中超过该值的有 8 个；排序已按 net 优先、中段长度次序，实验 B 可对过长中段的候选加长度代价。

## 5.1 估计精度：对精确 strict-D56 缓存的抽检

- Ranking 前 150 个候选：可构建 150 个，`estimated_net == exact_net` **150/150**，精确 D56 通过 **141/150**（94.0%）。
- 每条“有正收益候选”路由的最优候选（485 条路由）：`estimated_net == exact_net` **485/485**，精确 D56 通过 **481/485**。
- 被精确 D56 拒绝的少量候选是目标高度上的**间距过近**（不是交叉数估计错误），实验 B 的精确评估会剔除它们。

## 6. 结论：一次换层能否移除多个交叉？

- 能。数据中可行候选的最大 estimated_removed = 16，最大 estimated_net = **16**；net≥3 的候选 5851 个、net≥5 的 2799 个，说明一次换层可以同时移除（并避免新增）多个同层交叉。
- 正收益并不稀少（几何可行候选中 net≥1 占 71%），但按路由看只有 **485/656** 条可移动路由存在正收益候选；收益集中在交叉数最多的路由上。
- **关键限制**：同时满足世界模型真 3D 间距的候选很少——几何可行候选中 仅 156 个 world_3d_ok（1.35%），其中 net≥1 的只有 29 个、net≥3 的 1 个，最好 net = 3。这说明单次换层的**净收益上限受 3D 间距强烈约束**，实验 B 必须在使用前做完整 3D 校验，并预期实际可采纳的换层次数远少于候选数。
- 因此实验 B 的策略应是：只对 top 候选做批量换层，其余路由保持 2D 基线；并逐候选用精确 D56 + 完整 3D 校验确认后再接受。
