## 2. 基线复现

- 256 条人工 U + 48 条有二维几何的 Z2 接口线路；
- 不加入 L7/L8；
- 结果 **12 / 48**，通过线路：642, 643, 645, 646, 647, 648, 769, 770, 771, 772, 1017, 1020；
- 0 几何违规；
- 与历史独立实验的 12/48 完全一致，说明本轮 baseline 口径可复现，没有直接引用历史数字。

## 4. 实验 B 的负结果

- 允许深度 `Δd >= 0`，优先原深度，再按 0.25/0.5/1/2/4/8 mm 加深，并尝试外层嵌套链联动；
- 实际 `deepened_u = 0`、`total_depth_increase_mm = 0`；
- 最终 20/48 与 A 相同，接受改动集合完全一致；
- 结论：**在这批 48 条 Z2 路径和 256 条固定 XY 的人工 U 上，“加深 U”没有产生可接受的额外收益**。主要原因是嵌套链联动后的 U-U 净空约束和目标 Z2 blocker 不下降。

## 5. L7/L8 集成（A 方案）

| 指标 | 结果 |
|---|---:|
| 优化 U | 256 / 256 |
| 加入前 Z2 接口 | 20 / 48 |

| L7/L8 直接加入成功 | **137 / 255** |
| 加入后 Z2 接口 | **16 / 48** |
| L7/L8 加入后丢失的 Z2 | 647, 769, 770, 771 |
| 集成验证违规 | 0 |

对比：

- 原完整 Z1（511 条）固定后 Z2 接口 **0/48**；
- 优化 U + 20 Z2 + 137 条 L7/L8 后 Z2 接口 **16/48**；
- 但 L7/L8 只恢复 **137/255**，相对原 255 条少 118 条，不能宣称整体 1024 全量改善；
- 剩余 L7/L8 失败需要局部 2D XY 引出重路由，本轮只做“现有几何直接加入”的下界测试。

## 6. 最终判断

1. **固定 U 深度只调两端 S 位置（A）有效**：12→20，恢复 8 条，U 全部合法，0 违规。
2. **加深 U（B）在本数据集/本搜索预算下无效**：0 条加深，20/48 与 A 相同。
3. **L7/L8 集成是折中**：Z2 接口兼容性 20→16，L7/L8 仅 137/255；需要联合重排 L7/L8 过渡/XY 才能进一步提升。
4. **同端口共轨的 12 条 same-side 接口线路是硬限制**：不改变 XY 路径时，深度和过渡位置无法解决。
