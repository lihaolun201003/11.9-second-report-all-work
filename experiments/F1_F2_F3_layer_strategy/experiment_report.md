# F1/F2/F3：1024 通道三维光波导分层布线与邻边专项优化实验

> 本报告来自本地真实运行产物（`four_side_1024/f123/` 管线）。所有交叉数字均来自
> `routes_1024.json` 的实际 XYZ 几何与冻结验证器/严格交叉统计。**未通过冻结验证的
> 方案如实标注 violations，没有用修改标签或示意几何代替真实结果。**

## 一、总体目标与基线

本轮研究 Z1 对边/邻边的分层策略，以及 Z2 作为独立 512 通道子系统（严格四元旋转对称）
对 1024 通道实际物理交叉的影响。

- 基线：E1 当前最优解 —— **3,594 对**全局唯一交叉，1024/1024、violations=0，
  Z1 2,608 / Z2 240 / 高层 746，L6 128 条、L7 0 条，升降段 1,240，加工 27.0060 h。
- 对称性：**Z1 不要求 C4**（NS/EW/邻边可独立选层、独立升降窗口、独立路径几何）；
  **Z2 必须严格四元旋转对称**（旋转中心 (75,75)，`R(x,y,z)=(150-y,x,z)`，以四元组为
  最小调整单位）；全部 1024 通道执行冻结几何/交叉验收。

## 二、固定几何与工艺参数

- 端口坐标/切向、1024 连接关系固定；板 150×150 mm；Z1=0.00、Z2=0.50 mm；
- R=15 mm、非交叉净空 0.08 mm、层间距 150 μm、写入速度 1 mm/s；
- 层栈：L2 0.65 / L3 0.80 / L4 0.95 / L5 1.10 / L6 1.25 / L7 1.40 mm；
- `fabrication_hours = total_xyz_length_mm / 3600`。

## 三、方法与实现（`four_side_1024/f123/`）

1. **Z2 四元组先行清空走廊**：以连接表 group 为 C4 轨道（Z2 = 128 个轨道），整轨道
   联合选择层与升降窗口，反向成员自动交换起终点窗口；Z2 的 128 个轨道在任何方案中
   都整体调整，保证 Z2 严格 C4。
2. **Z1 按预设策略分层**：从“接口层平铺 Z1 + 已优化 Z2”出发，逐条尝试 Z1 对边/邻边的
   目标层与结构合法 S 型窗口（起终点可不对称），失败按层回退并逐条记录
   `assignment_table.csv`。
3. **Z2 再优化**：给定 Z1 布局，继续以四元组为单位微调 Z2 层与窗口。
4. **窗口精修**：Z1 只改升降窗口（不改预设层）。
5. **冻结验证器修复**：对冻结验证器发现的三维净空违规，只回退 Z1 路线（不破坏 Z2 的
   严格 C4），残余违规数如实写入 `validation.json`。

## 七、F3：Z1 邻边选择性抬升

F3 以 F2 局部优化结果为起点。Z1 邻边 184 条中：

- **128/184** 条具备结构合法的 S 型直线窗口（引出段足够长）；
- 四角 0.125 mm 引出段的邻边路线无法用现有 S 模板抬升（几何限制）；
- 优化中尝试抬升 128 条（有窗口者），126 条成功变更；
- 冻结修复后**最终保留 94 条在 L3**（其余回退 L1）。

结果：9,814 对（Z1 8,310 / Z2 0 / 高层 1,504），升降段 1,198，加工 26.9509 h，
残余 240 个 clearance 违规。

## 八、验收问题回答

1. **F1 与 F2 哪种分层策略更好？** 构造阶段日志：F1 构造到 4,138 对（残余 100 违规），
   F2 初始构造到约 8.1k 对（残余 241 违规）；本实现中 F1（EW→L2 + NS 留底层）交叉更少。
   但两者都未达 violations=0，**不能宣称一种策略已被验证优于另一种**。
2. **F2 中 NS、EW 实际进入目标层数量？** NS 132 条中 **94 条进入 L2**（33 留 L1、
   5 改 L4）；EW 132 条中 **86 条进入 L3**（30 留 L1、13 改 L2、3 改 L6）。逐条见
   `assignment_table.csv`。
3. **Z2 独立优化后自身交叉降低多少？** 接口层 Z2 交叉由基线 240 降为 **0**（Z2 全部
   离开接口层），代价是高层交叉上升（F1 148、F2 局部 1,366）。Z2 以自身+全局为独立
   优化目标，不是单纯给 Z1 让路。
4. **L4–L7 分别用了多少条？** F2 局部优化：L4=48、L5=108、L6=148、L7=12。
5. **F3 成功抬升多少条 Z1 邻边？** 最终保存布局 **94/184** 条在 L3。
6. **哪类邻边圆弧最容易抬升？** 两侧直线引出段较长（≥ S 型升降足迹）的邻边路线；
   0.125 mm 引出段的四角路线无法用现有 S 模板抬升（需要三维复合转向，本轮未实现）。
7. **能否突破 E1 的 3,594 对？** **否**。本轮无新方案达到 3,594；构造阶段最低 F1
   4,138（未通过冻结验收），最终保存方案 9,192–11,697。
8. **最优解 1024/1024、violations=0？** 全部方案 1024/1024 布通；**只有 E1 基线
   violations=0**。F1/F2/F3 分别残余 80/220/180/240 个三维净空违规，不满足最终验收。
9. **加工时间与升降次数变化？** 新方案 26.79–26.95 h（基线 27.0060 h），升降段
   950–1,198（基线 1,240）。
10. **图件位置？** 每组目录 `figures/` 内 22 张图：01_overall_3d、02_overall_xy、
    03_L1_Z1…10_L7、all_layers_contact_sheet、z1_before_after、z2_before_after、
    ns_ew_layer_separation、adjacent_routes_before_after、corner_routes_zoom、
    crossing_hotspots、transition_windows_3d；总对比图 `comparison.png`。

## 九、失败原因与局限（诚实记录）

- **构造合法 ≠ 冻结验收**：快速碰撞世界（0.088–0.12 mm 安全裕量）与冻结验证器对 S 型
  升降段三维净空的稠密采样判断仍有差距；残余违规主要是 `transition_vs_flat` 的
  0.06–0.078 mm 边缘近距，集中在 Z1 升降段与 Z2 接口/高层次平铺波导之间。
- **回退式修复会破坏分层策略**：把违规 Z1 路线回退接口层会显著增加交叉（每条约 +100
  对），并在路线间改变净空关系，因此修复后交叉数高于构造阶段。
- **时间约束**：冻结验证器单次全量验证约 5 s，逐条搜索/逐轨道修复难以在本轮内收敛到
  0 violations；按任务要求，失败方案如实保存而非伪造合法结果。
- **Z2 严格 C4 已达成**：所有方案 Z2 均为四元组整体调整，独立 C4 验证 PASS
  （128 轨道，最大偏差 2.84e-14 mm）；Z1 保持非对称，未被判为错误。
- **结论**：本轮给出完整实现与真实数据，但**没有产生优于 E1 3,594 且 violations=0 的
  方案**；E1 最优解仍是当前唯一完全合法的 1024 通道结果。
