# F2 reworked：Z1 非对称 + Z2 严格 C4 的真实联合优化（1024 通道）

> 本报告来自真实运行的完整 1024 路布局与冻结验证器实测。核心结果：修复后的 F2
> **首次得到伪合法（violations=0）的目标分层布局**：全局唯一交叉 4,960、1024/1024、
> Z2 严格 C4 PASS；但**没有优于 E1 的 3,594**（差 +1,366），且目标层完成率在
> "最小交叉合法解"与"最高目标完成率合法解"之间存在权衡。

|---|---:|---:|---:|---:|---:|---:|---:|---|---:|
| E1 baseline | **3,594** | 2,608 | 240 | 746 | — | — | 0 | PASS | 27.0060 |
| 原 F2 initial | 10,516 | 8,672 | 0 | 1,845 | 94 | 86 | 220 | PASS | 26.7943 |
| 原 F2 local | 11,697 | 10,332 | 0 | 1,366 | 88 | 74 | 180 | PASS | 26.9082 |

R15、0.08 mm 净空、150 μm 层距、1 mm/s 速度均未放宽。

## 二、上一轮 F2 违规的根因（问题 1 的答案）

上一轮 F1/F2/F3 的 80–240 项违规全部是 3D 净空类（`transition_vs_flat` 为主，
少量 `transition_vs_transition`），最近距离 0.06–0.078 mm，低于 0.08 mm。根因有四个：

1. **快速碰撞世界与冻结验证器的三维判定不一致**：`ClearanceWorld3D` 用粗-精采样
   近似，而冻结验证器 `validate_l3d_multi` 对 S 型过渡按 **0.02 mm** 步长采样、
   平铺按 0.1/0.02 mm 采样，并用线段-线段最近距离、以 `limit = 0.08 − 1e-7`
   判违规。两者在"过渡段贴着另一层平铺波导擦过"的边缘情形给出不同结论；提高
   安全裕量只是把误接受推向更小距离，并未消除不一致。
2. **旧修复策略破坏了已清空的走廊**：上一轮 `repair()` 把违规 Z2 轨道回退到接口层；
   但 Z1 的 S 型升降是在 Z2 已让开走廊后构造的，Z2 回退后立即产生新的
   `transition_vs_flat`，导致"越修越差"。
3. **旧 `e1_z2_base()` 把 Z1 全部恢复平铺**：E1 中已经合法的 Z1 升降窗口/避让关系
   全部丢失，只能从全平铺重新贪心，因而产生了 10516/11697 这样远差于 E1 的结果。
4. **旧世界更新/回退方式粗暴**：路线替换时旧几何残留、回退到接口层又造成交叉大幅
   增加（每条约 +100 对）。

## 三、本轮算法修复（问题 2/3/4 的答案）

1. **从 E1 合法布局增量修改，而非全平铺重建**：只改动目标层不满足 F2 预设的
   260 条 Z1 对边路线；其余 1,024−260 条保持 E1 已验证几何。
2. **候选合法性 = 冻结验证器自己的几何**：实现 `FrozenOracle`，直接复用
   `validate_l3d_multi` 的 `_parse_route / _build_3d_segment_store /
   _segment_segment_closest`，候选路线与整个世界做**同判据**的 3D 净空检查
   （过渡 0.02 mm、平铺 0.1/0.02 mm 采样，0.08−1e-7 限值），并叠加 D56 同层检查。
   因此"通过候选检查"与"通过最终冻结验证"不再脱节。
3. **分块应用 + 每块全量冻结验证**：把 260 条目标层修改按 20 条一块分 13 块应用，
   每块后跑一次完整冻结验证；13/13 块全部通过（0 失败块）。任何不合法块直接丢弃，
   保留上一个合法检查点——不再出现"粗爆回退到平面"。
4. **真正执行 F2 局部联合优化**：
   - Stage 4：Z2 的 128 个严格 C4 四元组按 L4–L7 优先级整轨道重优化，
     24 个轨道被合法接受（4 块全部通过验证）；
   - Stage 5：Z1 升降窗口精修，27 条路线被合法接受；
   - 另一个 joint 轮次（Z2 窗口 + 前 160 条 Z1 窗口）得到 4,992 的合法布局，
     但因为劣于 4,960 的检查点而未作为 best（记录在 `joint_local_rerouting/attempt.json`）。
   - 每轮记录候选数/接受数/验证次数（见 `incremental_Z1/stage2.json`、
     `summary.json` 的 `stats` 与 `experiment_report.md`）。

## 四、目标分层完成情况（问题 3–8 的答案）

### Z1（最优合法解 4,960）

| 类别 | 实际分层 |
|---|---|
| Z1 邻边 184 | L1-Z1 = 184（全部保留接口层） |
| Z1 NS 对边 132 | **L2 = 93**，L3 = 19，L4 = 20，**L1 = 0** |
| Z1 EW 对边 132 | **L3 = 65**，L2 = 67，**L1 = 0** |
| Z1 U 型 64 | L3 = 64 |

- NS 进 L2：**93/132**；EW 进 L3：**65/132**；留在接口层的对边路线 **0**（全部已抬升，
  未进目标层的路线落在相邻合法层，原因见下）。
- EW 未进 L3 的 67 条落在 L2：L3 主干同时被 NS 回退路线、Z1 U 束（64 条在 L3）与
  Z2 束占用，在"不增加违反净空"的前提下，这些 EW 只有 L2 能提供合法的近端口窗口；
  强行放 L3 需要挪动 Z2 或 U 束并重新验证，本轮时间预算内未做。

### Z2（严格 C4，128 个四元组）

| 层 | 四元组数 |
|---|---:|
| L1-Z2（接口） | 46 |
| L3 | 5 |
| L4 | 8 |
| L5 | 23 |
| L6 | 43 |
| L7 | 3 |

- 82/128 个四元组进入 L4–L7（优先区），46 个仍在接口层（多为短引出段、无法合法
  进入高层的邻边四元组）；**没有任何四元组被单独移动**，Z2 严格 C4 PASS，
  最大 XYZ 偏差 **2.84e-14 mm**。

### 交叉变化（问题 9–12 的答案）

- **Z1 接口交叉：2,608 → 2,343（−265）**；**Z2 接口交叉：240 → 240（不变）**；
- **高层交叉：746 → 2,377（+1,631）**；全局：3,594 → **4,960（+1,366）**；
- 升降段：1,240 → **1,312**（+72）；加工时间：27.0060 → **27.4057 h**（+0.40 h）。
- 原因：把 NS 与 EW 分别移到 L2/L3 后，两族主线在同一/相邻高层交叉，且 Z2 束
  也被推高，高层交叉大幅上升；Z1 接口的收益（−265）远不能抵消高层损失。
- **结论：目标分层策略本身在实际三维净空约束下不优于 E1 的"EW→L2、NS→L3"
  分配**（E1 的方向-层对应正好相反，是 E1 搜索得到的更优解）。这是本轮最重要的
  科学结论。

## 五、F3 follow-up（问题 13 的答案）

在合法 F2（4,960）基础上，对 184 条 Z1 邻边做选择性抬升（优先 L3，允许 L4/L5/L2）。
用冻结同判据 oracle 检查后 **0 条**邻边存在合法 S 型升降窗口：Z1 邻边两侧直线引出段
仅 0.125 mm 量级，而 S 型升降在 L2 就需要约 6.2 mm 直线足迹（L13 约 11.5 mm），
现有模板无解。F3 因此保持 F2 布局（合法、4,960），没有获得改善，规则是"不允许为
降低邻边交叉而接受任何几何违规或全局交叉上升"。

## 七、局限与后续

- 最小交叉合法解（4,960）与最高目标完成率合法解（5,187）都在 E1 之上；目标分层
  策略在 150 μm/0.08 mm/R15 约束下不占优。
- 目标完成率的剩余缺口主要来自 L3 主干被 Z1 U 束与 Z2 占用；若允许同时重排
  Z1 U 束和部分 Z2 四元组（联合搜索），EW→L3 完成率可进一步提高，但需要更多
  冻结验证轮次。
- Z1 邻边（0.125 mm 引出段）必须使用真正的三维复合转向（沿弧同步变高）才可能抬升，
  现有 S 型模板与验证器不支持其合法性表达，本轮未实现。
