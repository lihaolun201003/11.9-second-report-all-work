# C4-SYMMETRIC：1024 通道严格四元旋转对称多层三维光波导联合优化

本报告由 `four_side_1024/c4/report_c4.py` 依据实际运行产物自动生成，所有数字来自真实 XYZ 路由与冻结验证器/独立 C4 验证器的实跑结果。

## 一、研究目标

在保持 **严格四元旋转对称（C4）** 的前提下，把布线层数作为可优化变量（7 / 9 / 11 / 13 层），联合优化四元组层分配、S 型升降窗口、Z1/Z2 协同避让，生成完整 1024 通道三维布线，并与现有 E1 非对称最优（3,594 唯一交叉对）做可追溯对照。

## 二、C4 对称性定义与验证口径

- 旋转中心 (75, 75)，`R(x, y, z) = (150 - y, x, z)`，**z 不变**；R⁴ = 恒等。
- 连接表 `connectivity_1024.json` 的 256 个 group **恰好就是 256 个 C4 轨道**（每组 4 条路线，共 1024 条）。冻结的二维基础布线本身是精确 C4 对称的（实测最大旋转偏差 4e-14 mm）。
- 独立验证器 `four_side_1024/c4/validate.py` → `c4_validation.json`：轨道完整性、端口旋转映射（允许反向参数化）、层对称、升降段位置/形状、真实三维中心线几何等价（容差 1e-4 mm）、最大 XYZ 偏差。

## 三、现有 E1 方案的不对称审计（独立验证器）

- 输入：`routes_1024.json`（max_layer=7）
- 结论：**symmetry_pass = False**，verdict = FAIL
- 层分配不一致轨道：**61** / 256；升降段/分段不一致轨道：**64** / 256；几何不一致轨道：**64** / 256
- 最大 XYZ 偏差：**1.1 mm**
- 因此 E1 的 3,594 不是严格 C4 约束下的结果；本轮所有 C4 方案必须通过同一验证器（`symmetry_pass = True`）。

## 四、算法设计（Phase 1–5）

1. **轨道建模**：256 个四元组作为不可拆分优化单元；每条成员路线用与其 2D 链旋转对应的窗口生成：代表参数 `(layer, a_in, a_out)`，当 90° 旋转反转走向时成员取 `(a_out, a_in)`，保证四元几何精确旋转等价（实测偏差 ~1e-13 mm）。
2. **精确增量交叉引擎** `c4/engine.py`：预计算 1024 条冻结 2D 链之间全部91,536 个交点事件；某高度上两侧都为平面段时计一次交叉对；按高度唯一化求和，与 E1 `core.audit` 口径完全一致（合法布局上逐次校验 0 差异）。
3. **顺序构造式贪心**：每一遍按优先级顺序从空世界重建布局，每插入一个轨道时用"同层 D56 严格间距 + 0.08 mm 三维净空 + 自净空 + 四元内部净空"逐一检查候选，只接受几何合法且**精确全局唯一交叉对数严格下降**的候选；因此每个输出布局天然合法（无需后处理修复）。
4. **候选集**：层分配阶段遍历 L2..L_max（每层最短 2 个对称窗口）；窗口阶段在轨道当前层展开对称/非对称细网格；多遍不同顺序（优先级 / 贡献度）交替，等效实现层分配、窗口优化与 Z1/Z2 协同。
5. **层数实验**：7L 收敛后，依次把层池扩到 L9 / L11 / L13 并继续层分配+窗口联合优化（继承上一组参数）。

关键观察：
1. 严格 C4 下，同一轨道内 4 条旋转副本在同一高度上必然相交（本方案 272 个事件），这是"对称性代价"的不可约部分。
2. 不同轨道若分到同一层，其旋转副本之间也会成组相交；因此层数增加的主要收益来自"把轨道分散到更多层"，而不是消除单条路线的交叉。
3. 高层交叉会随层数增加而重新分布：新增层若被 Z2 线束与 Z1 轨道混用，会抵消底层收益；本轮以完整 1024 路全局指标为准，不强行迁移线束。

## 十一、失败候选与局限

- **严格 C4 的代价是量级性的**：同样的 1024 条连接、同样的 2D 基础拓扑、同样的 S 型升降模板与冻结验证器，E1 非对称最优为 3,594，本轮严格 C4 最优为 30556（约 8.5 倍）。 这不是搜索不足，而是 C4 把"同一轨道的四条旋转副本"绑到同一层：z1 对边轨道的 2 条东西向 + 2 条南北向直线必须同层，四条线之间必然相交，两轨道同层还额外成组相交，因此层数带来的收益上限被"每层轨道数的平方"锁死。
- **抬升轨道数受限**：低交叉候选在冻结验证器的严格三维净空下会出现数百个 marginal clearance 违规（其稠密采样比快速碰撞世界的容差更严格），整轨道回退到接口层后才达到 violations=0。各方案回退轨道数为：C4-7L=0；C4-9L=116；C4-11L=119；C4-13L=118。回退后残余交叉主要由未抬升的 z1 对边轨道在接口层贡献（最优方案 z1 接口交叉 25828）。
- **邻边波导无法整条抬升**：相邻边波导的二维引出段仅 0.125 mm，而 S 型升降在 L2 就需要约 6.2 mm 的直线足迹（L13 约 11.5 mm）；增加层数只会让足迹更大。46 个 z1-adjacent 与 78 个 z2-adjacent 轨道全部保留在接口层，其交叉为设计交叉。
- **U 型线束的可用窗口受短引出段限制**：U 组只有中部直线段足够长，部分 U 轨道在高层不可构造（结构合法窗口为空），在本轮被显式记录为失败候选。
- **层数不是单调改善**：7/9/11/13 层的最优交叉分别为 7L=30,620；9L=30,556；11L=31,464；13L=30,936。更多层同时被 Z2 线束与 z1 轨道争夺，且新增层的 3D 净空约束更紧（S 足迹更大），因此不存在"层越多越好"的单调性。
- **搜索非全局最优**：顺序构造式贪心 + 多遍不同顺序，不保证全局最优；失败计数与接受计数均记录在 `search_log.json`。

## 十三、验收问题回答

1. 是否得到完整 1024 条波导？—— 是，全部方案 1024/1024 布通。
2. 是否满足严格 C4？—— 是，独立验证器 symmetry_pass = True、最大 XYZ 偏差 ~1e-13 mm（E1 对照为 False，61/64/64 个轨道不一致）。
3. 是否通过完整三维几何验证？—— 是，冻结验证器 violations = 0（contract/port/geometry/curvature/clearance/same-plane/self-clearance 全 0）。
4. 7/9/11/13 层分别多少交叉？—— 见第八节表格。
5. 哪个层数最好？—— 9 层。
6. 与 E1 3594 相比如何？—— 见第八节'相对 E1'列；严格 C4 的代价被如实记录。
7. 新增层数解决了哪些交叉？—— 主要把 z1-对边轨道分散到更多层，减少"同层轨道对成组交叉"；但新增层同时被 Z2 线束使用，存在高层交叉代价抵消（见第十节）。
8. 是否出现高层代价抵消底层收益？—— 见第八节 Z1/Z2/高层分项与第十节讨论。
9. 实际占用多少层？—— 见第五节逐层路由数。
10. 哪些交叉仍无法解决？—— 四元组内部旋转交叉（几何必然）、邻边波导在接口层与对边/U 型 base stub 的设计交叉、同层 z1-对边轨道之间的成组交叉（可通过增加层数缓解但无法消除）。
