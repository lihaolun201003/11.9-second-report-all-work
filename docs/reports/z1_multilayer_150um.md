# Z1 专项多层扩展与交叉最小化：150 µm 层栈实验（2026-10-30）

## 1. 背景与目标

本科毕业设计《1024 通道三维光波导自动布线系统》。历史 Hybrid-H 在旧层栈（L2=1.0 mm、L3=1.5 mm、L4=2.0 mm、L5=2.5 mm）下达到 1024/1024、12,960 全局唯一交叉，其中 Z1 相关约 92%。本实验把层栈改为工艺要求的 **0.15 mm 层距**，从 Z2 上方开始新增 L2…L11，优先优化 Z1 横纵主干，比较 5/7/9/11 层的真实收益。

固定参数：

- Z1 = 0.000 mm，Z2 = 0.500 mm，二者之间不新增布线层；
- L2 = 0.650 mm，L3 = 0.800 mm，…，L11 = 2.000 mm（每层 0.150 mm）；
- 1024 连接 / 2048 端口，曲率半径 R = 15 mm，非交叉净空 0.08 mm；
- 写入速度 1 mm/s，加工时间 = 完整 XYZ 中心线弧长 / 1.0。

## 2. 数据与方法

### 2.1 固定层与重新生成几何

所有层高写入新层栈 JSON，但**路线全部重新生成 XYZ**：历史路线不能只改 JSON 层高。Z1/Z2 接口仍作为 L1 的两个独立物理高度（0 与 0.5 mm）。

- 相邻连接（496 条）保持接口层平面几何；
- 同侧 U（64 个四元组，256 条）从历史 Structured-A 几何按新层高重算 S 段；旧 L4 角部 U 束（组 160–175）在新 L4=0.95 mm 下与 L3=0.80 mm 的平面路线干涉，重新搜索嵌套深度链 D 和入口长度 a，最终 16 组全部重建为合法几何；
- Z2 对边（8 条）按新层高重算；
- Z1 对边 264 条 = 66 个四元组 = 66 个 EW C2 对 + 66 个 NS C2 对，是本实验的优化对象。

固定世界合计 760 条（相邻 + U + Z2 对边），在 5/7/9/11 层实验中保持不变；所有路线用同一份 `connectivity_1024.json` 与端口表。

### 2.2 Z1 冲突分析与层分配

1. 提取所有 Z1 相关路线并分类：EW 主干、NS 主干、同侧 U、相邻线；
2. 在固定世界（760 条）中逐对检查 C2 对的可升降窗口；
3. 方向分离：EW 对与 NS 对分别指定目标层（如 5L 的 EW→L4、NS→L5；7L 的 EW→L5、NS→L6；9L 的 EW→L7、NS→L8；11L 的 EW→L9、NS→L10）；
4. 对每个 C2 对扫描 a∈{1.2, 4, 9, 16, 24} mm 的升降起点，优先早升降以缩短 z=0 base 段；
5. 装配后若 3D 验证器报告 violations，则把涉及的 C2 对**整对**回退到基线几何，重复直到 violations=0；
6. 5L 基线保持历史 Hybrid-H 层策略：EW C2 对升 L2，NS 对平铺 z=0。

### 2.3 目标函数

字典序：

1. 1024/1024 布通且几何约束（3D 净空、R≥15 mm、端口/层序）全部满足；
2. 全局唯一物理交叉路线对最少；
3. 升降次数最少；
4. 总加工时间最短。

辅助统计：Z1 横纵交叉对、各物理高度交叉对/事件、Z1 z=0 交叉位置、逐路线长度。

## 4. 讨论

- **层数收益递减**：5→7 层略有改善（−16 对），7→9/11 反而变差。原因不是层数本身，而是当前算法只做整对单层分配 + 修复回退：新增层未被细粒度使用；同时高层 S 段穿越中间层，与 U/相邻线的 3D 约束增多，导致更多对回退到基线。
- **Z1 早升降有效**：缩短 base 段直接降低 z=0 横纵交叉；但端口附近的固定 U/相邻线使约 32–44 对无法早升降，仍保留基线窗口。
- **时间代价小**：0.15 mm 层距下 S 段变短，五组总长都在 97.2 m 附近（27.00 h @1 mm/s），比旧层栈 Hybrid-H 的 98.02 m 略短。
- **与历史 12,960 的关系**：历史值使用旧层栈，不能与新 5L 基线 13,920 直接等价；本实验的所有比较都在新层栈内完成。

## 5. 局限与后续

1. 层高仍是 `unconfirmed_simulation`，验证通过为 exploratory，不是正式工艺验收。
2. 优化范围只含 Z1 的 132 个 C2 对；同侧 U、相邻线、Z2 对边冻结为基线。
3. 未做线束级/每路线级分配、Rip-up & Reroute、多候选层联合搜索；9L/11L 的非单调是搜索不足，不是"层数无用"的证据。
4. 下一步可把 Z1 对按冲突图聚类成线束，每束独立选层；允许单条路线换层与升降窗口联合优化；再评估 9/11 层的真实上限。
